# Site vitrine — Objectif 10K Pas

Site statique bilingue (FR à la racine, EN dans `/en/`), sans dépendance.

- Modifier les textes dans `build.py`, puis `python3 site/build.py` (régénère les deux pages).
- Avant la mise en ligne : `scripts/set-domain.sh https://ton-domaine` (canoniques, Open Graph, sitemap, robots).
- Le badge « App Store » est un bouton texte : le remplacer par le badge officiel d'Apple si souhaité.
- Les captures viennent de `assets/` (datées d'avril 2026) : à rafraîchir si l'interface change.
- Politique de confidentialité : copie de `docs/privacy-policy.html` (en français uniquement).
